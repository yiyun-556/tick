把每一次稳住，都留在自己手里。

刻度是一个本地优先的克制打卡与冲动急救工具。它不要求账号，不把记录上传云端，也没有广告和排行榜。

状态稳定时，它帮你记下每一天；冲动上来时，它给你 60 秒呼吸引导，和一个可以说话的 AI 伴侣。

## 你可以用它

- 记录已稳住的天、小时、分钟
- 每天稳住打卡，补录过去某一天
- 记录一次，并留下当时的诱因和备注
- 在月历里回看每一天，给任意日期写备注
- 查看本月次数、平均间隔、最长连胜
- 在冲动时进入 60 秒 4-4-6 呼吸引导
- 和 AI 伴侣说话；不配置 Key 也能使用本地陪伴模式
- 把提醒、实时活动和打卡确认放在通知栏

## 安装

- 需要 Android 12 及以上
- 下载 `tick-v1.0.0.apk`
- 首次安装需要允许“安装未知应用”
- 首次启动会要求完整阅读隐私政策

## 关于隐私

打卡、备注、聊天和设置只保存在这台手机上。API Key 使用 Android Keystore 加密。

没有账号，没有云同步，没有广告 SDK，没有统计 SDK。
