刻度 · Tick把每一次稳住，都留在自己手里刻度是一个本地优先的 Android 应用：克制打卡 + 冲动急救。
它不要求账号，不把记录上传云端，没有广告，也没有排行榜。状态稳定时，它帮你记下每一天；冲动上来时，它给你 60 秒呼吸引导，和一个可以说话的 AI 伴侣。
